# GRiP AI outreach website

By the Electrified Entrepreneurs. Live at https://wizkidzai.github.io/grip-ai/girls-in-robotics/

- **Run it:** `npm install`, then `npm run dev`, then open http://localhost:5173/grip-ai/girls-in-robotics/
- **Check it:** `npm run lint`, then `npm run build`
- **Pages** are in `src/pages/`. The list of pages (the menu and the home buttons) is `src/pages.js`.
- **Links to other websites** are in `src/links.js`.
- **Publishing:** `.github/workflows/deploy.yml` builds this next to the arm app (`/grip-ai/arm/`).
