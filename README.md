# GRiP AI outreach website

By the Electrified Entrepreneurs. Live at https://wizkidzai.github.io/grip-ai/

- **Run it:** `npm install`, then `npm run dev`, then open http://localhost:5173/grip-ai/
- **Check it:** `npm run lint`, then `npm run build`
- **Sections** are in `src/pages/`. Their order and menu names are in `src/pages.js`.
- **Links to other websites** are in `src/links.js`.
- **Publishing:** `.github/workflows/deploy.yml` builds this at `/grip-ai/` and the arm app at `/grip-ai/arm/`.
